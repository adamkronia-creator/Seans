# Сеанс — психологический мессенджер (веб-приложение)

React + TypeScript + Vite. Сейчас мобильная версия (браузер), данные тестовые.

## Запуск
```
npm install
npm run dev
```
Открыть адрес из консоли на телефоне или в режиме мобильного устройства в браузере.

## Дизайн
- Шрифт Inter (переменный, с оптическими размерами: `@fontsource-variable/inter/opsz.css`), акцентный цвет `#0088FF`. Курсив — настоящая гарнитура `opsz-italic.css`: синтез наклона выключен (`font-synthesis: none`), и без нее курсивный текст остался бы прямым.
- Размеры текста берутся из шкалы в `tokens.css` (11 / 12 / 14 / 15 / 16 / 20 / 24, у каждого своя высота строки), отступы — из сетки 4 (`--space-*`), радиусы — `--radius-*`. Новые значения в стили экранов не добавляются: нужен другой размер — сначала шкала.
- Фон приложения плоский (`--color-bg-app`), карточки, шапки и списки белые, без теней; тень только у того, что парит (меню, кнопка «вниз», подсказки, нижние окна).
- Полосы прокрутки системные; скрыты только в рядах чипсов и в нижних окнах (там полоса сдвинула бы края).
- Справочные цвета для текста на белом: `--color-green-text`, `--color-yellow-text`, `--color-orange-text`, `--color-red-text` (яркие цвета палитры — для заливок и точек).

## Структура
- `src/styles/tokens.css` — цвета, шрифты, отступы, радиусы (дизайн-токены)
- `src/styles/motion.css`, `press.css` — движение: переходы между экранами, окна, меню, подсказки, подсветка нажатия
- `src/utils/transition.ts` — анимация смены экрана (View Transitions: вперёд, назад, плавная смена); адреса и направление — в `src/router.ts`
- `src/utils/pressEffect.ts` — нажатие как на телефоне (кнопка уменьшается и пружинит); `inertiaScroll.ts` — инерция колеса мыши; `exitAnimation.ts` — уход окон
- `src/components/SwipePager/`, `src/utils/swipe.ts` — листание страниц пальцем: разделы чата, фильтры по чипсам в списке чатов и в истории взаимодействия. Страницы идут за пальцем, пружина доводки, резинка у краёв; пузыри (`data-swipe-lock`) и блоки с боковой прокруткой (`data-hscroll`) договариваются с пейджером о жестах. Пейджеры вкладываются (`nested`: фильтры истории внутри раздела чата, жест принадлежит ближайшему, которому есть куда листать); у пейджера внутри прокручиваемого блока (`autoHeight`) высота по странице, а вертикальная прокрутка при смене страницы подбирается под неё. Чипсы подсвечивают страницу под пальцем (`onDrag`), выбранный чипс виден целиком (`src/utils/revealChip.ts`)
- `src/App.tsx`, `src/utils/edgeBack.ts` — экраны лежат слоями (под верхним уже нарисован тот, куда вернёмся): жест «назад» от левого края тянет экран вправо, а под ним виден предыдущий; вложенное «назад» внутри экрана (поиск в чате, бланк теста) заявляется через `useBackHandler` (`src/utils/backHandler.ts`)
- `src/components/EditSheet/useSheetDrag.ts` — нижние окна закрываются свайпом вниз
- `src/components/ChatBooking/`, `src/data/appointments.ts` — вкладка «Запись на прием» (самая левая в открытом чате; в «Избранном» ее и «Истории взаимодействия» нет). Предложение времени (точного или промежутка), согласие, отказ, ответ «другое время», перенос и отмена; ниже информация о приеме (карта, адрес, как пройти, что принести, оплата сеанса; текст общий для всех чатов, правится кнопкой «Изменить»). Данные пока только в памяти, ответы второй стороны не имитируются: входящие предложения заложены в исходные данные. Даты и время считаются в `src/utils/ruDate.ts`
- `src/pages/PlannerPage/`, `src/components/Planner/`, `src/data/planner.ts`, `src/data/agenda.ts` — раздел «Ежедневник» (первая вкладка нижней панели). Вверху календарь месяца (неделя с понедельника; точки под числом: синяя — сеансы и предложения времени, серая — дела, оранжевая — заметка дня; ручка под календарем сворачивает его до недели, на невысоком экране он сразу свернут), ниже распорядок выбранного дня по времени. В него собираются (`agenda.ts`, ничего не копируется): подтвержденные приемы из записи на прием, сеансы из истории клиента, свои запланированные сеансы и дела, а также предложения времени, на которые еще нет ответа, и отмененные приемы. Состояние сеанса: запланирован → подтвержден → идет сейчас → ждет отметки → состоялся / не состоялся. Отметка «Состоялся» создает сеанс в истории клиента (на дату приема, номера пересчитываются по порядку), «Не состоялся» сохраняется в самом приеме (в записи на прием в истории он тоже «Не состоялся»); снять отметку можно, пока у сеанса нет текста. Комментарий к состоявшемуся сеансу — это тот самый текст сеанса в «Истории взаимодействия» (`sessions[].paragraphs`): правка в любом из двух мест видна в другом. У клиентов без истории (все, кроме Максима) комментарий хранится в самом ежедневнике. Запланированный сеанс можно предложить клиенту (окно «Предложить время» из записи на прием): дальше он живет как предложение. Дела с галочкой и заметка дня с форматированием (мини-разметка, как в кейсе). Данные только в памяти; исходные записи считаются от сегодняшнего дня
- Карта места приема бесплатная и без ключей (`ChatBooking/geocode.ts`, `PlaceMap.tsx`): по нажатию «Показать на карте» адрес уходит в Nominatim (поиск OpenStreetMap), найденная точка показывается встроенной картой openstreetmap.org; до нажатия на сторонние адреса ничего не отправляется. Кроме того, ссылки «В картах»: Яндекс, 2ГИС, OpenStreetMap, Google. Правила Nominatim: не чаще запроса в секунду, без автодополнения; для большой нагрузки нужен свой геокодер
- `src/utils/bubbleGradient.ts` — градиент исходящих пузырей, как в Telegram: привязан к окну ленты (выше по экрану пузырь ближе к акценту, ниже глубже) и пересчитывается на прокрутку. Кнопка «Настройки теста» под тестом, отправленным клиенту, открывает окно `MessageBubble/SentTestSheet.tsx` с тем, с чем тест ушел; настройки лежат в самом сообщении (`testOptions`)
- `src/components/` — Avatar, Badge, Chip (число в кружке), SearchField, ChatItem, TabBar, icons, ComingSoon (пустой раздел нижней панели со значком раздела; пока только «Материалы для чтения»)
- `src/pages/MessagesPage/` — экран «Сообщения»
- `src/data/chats.ts` — тестовые чаты
- `src/assets/` — иконки (SVG), аватарки. Иконки вкладки «Запись на прием» лежат в `assets/icons/booking/` и подключены в `components/icons/index.tsx`: все присланные (`status-*` — статусы в истории приемов: `done` состоялся, `cancelled` отменен или отказ, `moved` перенесен, `pending` не согласован); значок можно заменить файлом с тем же именем; значок самой вкладки — `chat/tab-booking.svg` (цвета `#0088FF`/`#1E1E1E`/`#818C99`/`#A0A9B3` при сборке становятся цветом текста)
